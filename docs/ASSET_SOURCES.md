# 그래픽·라이브러리 출처와 라이선스

확인일: 2026-11-27

## 1. 별빛 꼬리 마을 그래픽 — 전부 원본(코드 생성)

마을의 **모든 그림**(주인공, 강아지·고양이, 집·나무·분수·가구 같은 소품, 지형, 아이콘, 효과)은 이 저장소의
코드가 직접 그립니다. 외부 이미지 파일을 가져다 쓰지 않았습니다.

| 파일 | 내용 |
|---|---|
| `js/game/pixel.js` | 픽셀 하나씩 찍는 그리기 도구(타원·다각형·윤곽선·명암) |
| `js/game/sprites.js` | 주인공, 강아지, 고양이 (방향별·걷기 프레임) |
| `js/game/props.js` | 집, 상점, 나무, 분수, 가구, 채집물 등 소품 |
| `js/game/world.js` | 지형(풀·물·돌길·광장), 건물 배치, 충돌 |

따라서 이 그림들에 대해 별도 저작권 표기가 필요한 제3자 자료는 없습니다.
(저작권은 이 프로젝트 저작자에게 있습니다.)

## 2. 무료 그래픽 자료 조사 결과 (사용하지 않음)

지시서가 우선 후보로 든 곳을 조사했습니다.

| 후보 | 확인한 내용 | 결정 |
|---|---|---|
| Kenney (https://kenney.nl/assets) | 모든 에셋이 CC0(퍼블릭 도메인)이며 상업 이용 가능. "Tiny Town"은 16×16 픽셀, `rpg/town/overworld` 태그. | **사용 안 함** — 직접 내려받을 수 있는 파일 주소를 확인하지 못했고, 평면적인 그림체가 참고 이미지(윤곽선·명암이 풍부한 따뜻한 정원 그림체)와 달라 섞으면 화풍이 깨질 위험이 큼 |
| OpenGameArt (https://opengameart.org/) | 자료마다 라이선스가 달라(CC-BY, CC-BY-SA, GPL 등) 파일별 확인이 필요함 | **사용 안 함** — 시간 안에 파일별 확인·고지를 마칠 수 없고, 조건이 불명확한 자료는 쓰지 않는다는 원칙에 따름 |
| itch.io 무료 픽셀 아트 (https://itch.io/game-assets/free/tag-pixel-art) | 자료마다 배포 조건이 다르고 다운로드에 별도 절차가 필요함 | **사용 안 함** — 위와 같음 |

> 무료라는 사실만으로 재배포 권한이 있다고 가정하지 않았습니다.
> 나중에 외부 자료를 쓰게 되면 이름, 제작자, 공식 URL, 라이선스, 확인일, 사용 파일, 수정 내역을 이 표에 추가하세요.

## 3. 참고 이미지 (프로젝트에 포함하지 않음)

사용자가 제공한 픽셀 아트 시안 6장(정원, 마을 지도, 광장, 캐릭터·동물 시트, 게임 화면 구성)은
**그림체와 화면 구성을 따라 그리기 위한 참고 자료**로만 보았습니다. 파일을 저장소에 넣거나 게임에 사용하지 않았습니다.

## 4. 앱에서 쓰는 외부 라이브러리 (이전 작업에서 포함)

| 이름 | 용도 | 라이선스 | 위치 |

| 행정안전부 동물병원 인허가 데이터 | 병원 위치 | 공공데이터 | `data/hospitals.json` |
