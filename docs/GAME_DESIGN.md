# 별빛 꼬리 마을 — 게임 설계 (1차)

> `별빛 꼬리 마을`은 가칭입니다. 기존 "반려동물 추억 저장소" 앱 안의 부가 기능(돌보기 탭 → 마을 들어가기)이며,
> 같은 앱·같은 주소에서 가로 전체 화면으로 열립니다. 별도 사이트로 분리하지 않습니다.

## 1. 기술 선택

- **직접 만든 Canvas 2D 엔진** (Phaser 미사용). 이유:
  1. 기존 프로젝트가 의존성 없는 순수 JS(ES 모듈) + PWA 오프라인 캐시 구조라, 1MB가 넘는 엔진을 더하면 첫 로딩과 캐시가 무거워짐
  2. 필요한 기능이 타일 지형·깊이 정렬·카메라·조이스틱·간단한 충돌뿐이라 직접 구현이 가볍고 검증하기 쉬움
  3. 모든 그림을 코드로 그리기 때문에 정수 배율·픽셀 단위 제어를 엔진 없이도 완전히 통제할 수 있음
- 3D 엔진 미사용. 모든 그림은 2D 픽셀 단위.

## 2. 그래픽 규칙 (일관성)

| 항목 | 값 |
|---|---|
| 타일 | 16px, 지도 96×64타일 (1536×1024px) |
| 마을 소품 | 1배 밀도 (집 112×96, 나무 56×54 등) |
| 주인공·반려동물 | **2배 밀도**(주인공 52×72, 반려동물 64×52)로 그려서 `CHAR_SCALE = 0.5`로 찍음 → 표정·머리결·털 표현이 살아나고, 월드 크기는 1배 소품과 어울림 |
| 화면 배율 | 화면 크기에 맞춰 **짝수 정수 배율**(2, 4, …) × 기기 배율. 보간 없음(`imageSmoothingEnabled=false`) → 캐릭터의 한 칸이 화면의 정수 픽셀이 됨 |
| 윤곽선 | 닿은 색보다 어두운 색으로 자동 1겹(`outline`), 위쪽은 밝게·아래쪽은 어둡게(`bevel`) |
| 난수 | 고정 씨앗 → 접속할 때마다 마을이 똑같음 |

## 3. 지도 (타일 좌표)

| 구역 | 범위(x, y) | 내용 |
|---|---|---|
| 우리 집 정원 | 4–33, 34–62 | 붉은 지붕 집, 벚나무, 울타리, 텃밭, 개집, 우편함, 가로등, 피크닉 담요, **가구 놓는 구역(8–30, 49–59)** |
| 마을 광장 | 38–66, 33–58 | 분수, 상점(시계탑), 가판대 3, 벤치, 가로등, 안내판, 꽃 화분 고리 |
| 속삭이는 숲 | 2–70, 2–33 | 나무·덤불·벚꽃 공터·연못, 채집 지점 대부분 |
| 광산 입구 | 70–94, 2–20 | 외형과 위치만 (**준비 중**) |
| 달빛 호수 | 66–94, 20–53 | 호수, 부두(낚시터 자리, **준비 중**), 폭포, 벤치 |
| 농장 | 66–94, 53–62 | 밭 4, 풍차, 허수아비, 건초 (**준비 중**) |

시냇물(x≈34)은 돌다리(31–38, 51–53)로 건넙니다. 길은 `PATHS`(징검돌)로 정의되어 있어 고치기 쉽습니다.

## 4. 상호작용 지점 (2차 개발에서 연결할 곳)

`world.interacts`에 `{ id, kind, x, y, r, label, text }`로 들어 있습니다.

| id | kind | 현재 동작 | 2차 계획 |
|---|---|---|---|
| `home-door` | home | 돌보기 탭의 기존 방(우리 집)으로 이동 | 2D 실내 |
| `shop` | shop | 상점(가구 사기, 채집물 팔기) | 상품 확대 |
| `board`, `forest-sign`, `lake-sign` | info | 안내문 | 퀘스트/안내 |
| `mine` | wip | "준비 중" | 광산 채굴 |
| `pier` | wip | "준비 중" | 낚시 |
| `farm` | wip | "준비 중" | 농사 |

새 활동을 연결할 때는 `kind`를 추가하고 `village.js`의 `useInteract()`에서 처리하면 됩니다. 지도를 다시 만들 필요는 없습니다.

## 5. 시스템

- **이동**: 가상 조이스틱(터치) / 방향키·WASD(데스크톱). 발밑 상자(10×4)로 충돌. 축별로 움직여 벽을 따라 미끄러짐.
- **가림 순서**: 모든 물체를 발밑 y로 정렬해 그림. 나무·건물 뒤에 서면 반투명 처리.
- **카메라**: 주인공 추적(부드럽게), 지도 가장자리에서 멈춤.
- **반려동물** (`updatePets`): 상태 `idle / look / wander / approach / toRest / rest / happy / follow`. 아이마다 성격값(돌아다님·쉼·호기심)과 속도가 달라 같은 순간에 같은 행동을 하지 않음. 정원에 방석이 있으면 쉬러 감.
- **교감**: 가까이 가면 `쓰다듬기`(하트 효과, 기존 친밀도 경험치 +1, 6초 간격) / `산책 동행`(한 마리, 뒤따라옴).
- **채집**: 꽃·열매·나뭇가지·반짝이는 조각 31곳. 한 번 채집하면 같은 날 비활성. **매일 오전 5시(한국 시간, `UTC+9`)** 에 갱신 (`dayKey()`는 기기 시간대와 무관하게 UTC 기준으로 계산).
- **지갑**: 기존 코인(아이별 `characters[].coins`)의 합 + 마을 주머니(`purse`). 쓸 때는 주머니 → 코인 많은 아이 순으로 차감. 채집물을 팔면 주머니에 쌓임. 기존 코인은 늘리지 않음(유료 재화·광고 없음).
- **정원 꾸미기**: 방석 40 / 화분 30 / 벤치 60코인. 아래 칸에서 고르고 `놓기`. 정원 구역 안에서만 가능하며 위치 저장. 가구 정의(`FURN`)는 이름·가격·그림·크기·충돌을 따로 두어 추가가 쉬움.
- **낮밤**: 기기 시계 기준(20~5시 밤, 5~7시·18~20시 전환). 밤에는 어두워지고 가로등·창문이 빛남.
- **친밀도는 줄지 않음**: 접속하지 않아도 마을에서는 아무것도 줄지 않고, HUD의 하트는 친밀도(경험치) 진행도임. (기존 "우리 집" 방의 배고픔/기분/청결이 시간에 따라 내려가는 동작은 이전 그대로.)

## 6. 저장 (IndexedDB v4, 새 저장소 `game`)

`id = 'village'` 한 줄:

```js
{ id, v, name,                       // 플레이어 이름
  x, y, dir,                         // 위치·방향
  companionId,                       // 산책 동행 중인 아이
  bag: { flower, berry, stick, gem },
  gathered: { '<지점id>': 'YYYY-MM-DD' },   // 오전 5시 기준 날짜
  owned: { cushion, pot, bench },    // 가진 가구(놓지 않은 것)
  placed: [{ uid, type, tx, ty }],   // 정원에 놓은 가구
  purse,                             // 마을 주머니 코인
  petPos: { '<petId>': [x, y] }, seenHelp }
```

- 백업·복원에 포함(`BACKUP_STORES`). 예전 백업(게임 없음)도 복원됨.
- 기존 저장소(`pets/posts/events/characters/meta`)는 구조를 바꾸지 않았음. 아이를 삭제하면 마을에서는 그 아이가 사라지고(동행 해제), 저장된 위치는 무시됨.
