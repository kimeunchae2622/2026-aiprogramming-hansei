## 추가로 확인한 것

- 세로 화면에서 "폰을 가로로 돌려 주세요" 안내와 돌아가기 버튼 표시, 가로로 돌리면 이어서 진행
- 첫 진입 시 로딩 화면 → 도움말, 이후에는 도움말 생략
- 밤 장면(어두워짐, 가로등·창문 빛), 나비·벚꽃잎·굴뚝 연기·물 반짝임 효과
- 상점 팔기(채집물 → 주머니 코인) / 사기, 코인 합계 계산
- 한 프레임에서 오류가 나도 게임이 멈추지 않는 안전장치(오류 120회 초과 시에만 닫음)
- 프레임 속도 약 130fps(데스크톱 브라우저). 마을 첫 생성 약 1.2~2초(폰은 더 걸릴 수 있어 로딩 화면 표시, 한 번 만든 뒤에는 재사용)

## 시험 중 찾아서 고친 문제

| 문제 | 원인 | 조치 |
|---|---|---|
| 게임이 첫 화면에서 멈출 수 있음 | 화면 시계가 시작 시각보다 앞서면 경과 시간이 음수 → 분수 애니메이션 번호가 음수 → 그리기 오류로 루프 종료 | 경과 시간을 0 이상으로 제한, 번호 계산 보정, 프레임 오류 방어 |
| 반려동물이 방석으로 가다 멈춤 | "방석으로 가기" 상태의 제한 시간 누락 | 제한 시간 설정 |
| 쓰다듬기 후 오류 반복 | 끝난 상태가 정리되지 않아 목표 좌표가 비어 있음 | 상태 정리 + 목표 없을 때 안전 처리 |
| 텃밭·농장 밭 위에 바위·꽃이 놓임 | 무작위 배치가 손으로 꾸민 구역을 몰랐음 | 해당 구역 제외 |
| 나무 뒤에서 주인공이 안 보임 | 가림 순서가 정직하게 적용됨 | 뒤에 서면 반투명 |
| 폰에서 전체 화면 요청이 거부될 수 있음 | 마을 생성이 몇 초 걸리면 "버튼을 누른 직후" 조건이 지남 | 전체 화면·가로 고정을 버튼 누른 즉시(동기) 요청 (호출 시점 확인) |
| 업데이트할 때 "저장 기능을 쓸 수 없어요"가 뜰 수 있음 | 다른 창이 예전 DB 연결을 붙잡으면 업그레이드가 막히고 바로 실패 처리 | 다른 창 연결을 자동으로 닫고, 막히면 4초 기다린 뒤 판단 (삭제·업그레이드 시험에서 지연 없이 통과) |

## 미확인 / 알려진 한계 (정직하게)

- **실제 Android·iPhone 시험 없음**: 터치 감각, 성능(저사양 폰), 전체 화면·가로 고정 요청, iPhone 사파리의 주소창 영향은 확인하지 못했습니다. iPhone은 가로 고정을 지원하지 않아 회전 안내를 표시합니다.
- **기존 실제 데이터(사진 포함)로의 DB 업그레이드 시험 없음**. 코드상 새 저장소만 추가합니다.
- **GitHub Pages 실제 폰 접속 미확인**(배포 주소 응답만 확인).
- 그래픽: 시안보다 단순합니다. 캐릭터의 걷기 프레임은 2장(다리·팔 교대), 반려동물 걷기도 2장이며 꼬리 흔들기 같은 세밀한 모션은 없습니다. 집 안(실내)은 기존 2D 방 화면을 그대로 씁니다.
- 광산·낚시·농사는 준비 중 표시만 있습니다(계획대로).
- 효과음·배경음악 없음.
- 밤 판정은 기기 시계(현지 시간) 기준이며, 채집 갱신만 한국 시간 5시 기준입니다.
