## 구현 완료 (실제 실행으로 확인)

- **가로 독립 화면**: 전체 화면·가로 고정 요청(버튼 누른 즉시), 세로면 회전 안내, 뒤로 가기·설정·집 문으로 종료, 로딩 화면
- **주인공**: 방향별 정지·걷기, 터치 조이스틱과 키보드, 충돌, 카메라 추적, 이름 저장, 외형(머리·원피스·피부) 선택 구조
- **그래픽**: 코드로 그린 픽셀 아트. 주인공·반려동물은 2배 밀도, 정수 배율 확대, 윤곽선·명암 통일, 가림 순서(나무·건물 뒤는 반투명)
- **마을 4구역 + 준비 중 3곳**: 우리 집 정원 / 마을 광장 / 속삭이는 숲 / 달빛 호수(부두) + 광산·농장·낚시터(외형과 위치만, "준비 중" 안내). 모든 곳을 걸어서 갈 수 있음(길찾기 검증)
- **반려동물**: 앱에 등록한 모든 아이 등장(1마리여도 가능), 마리마다 다른 성격값으로 자율 행동(돌아다니기·멈추기·쉬기·바라보기·다가오기), 방석이 있으면 거기서 쉼
- **교감**: 가까이 가면 쓰다듬기(하트, 친밀도 +1 저장), 산책 동행(뒤따라옴). 친밀도는 접속하지 않아도 줄지 않음
- **채집**: 꽃·열매·나뭇가지·반짝이는 조각 31곳, 가방 저장, 같은 날 재채집 불가, 한국 시간 오전 5시 갱신(기기 시간대와 무관)
- **상점·정원**: 광장 상점에서 가구(방석·화분·벤치) 구매 + 채집물 판매, 정원 구역에 놓기·치우기, 위치 저장. 기존 코인(아이별 코인 합 + 마을 주머니) 사용, 새 유료 재화·광고 없음
- **분위기**: 낮밤(기기 시계), 벚꽃잎, 나비, 굴뚝 연기, 물 반짝임, 숨쉬기, 걷는 먼지
- **저장·백업**: 새 `game` 저장소, 백업·복원 포함, 예전 백업 복원, 이전 버전(v3) 데이터로 업그레이드 시험 통과
- **문서**: `docs/GAME_DESIGN.md`, `docs/ASSET_SOURCES.md`, `docs/TEST_RESULTS.md`, 이 보고서, `PROJECT_HANDOFF.md`, `notes/time-log.md`, `README.md`

## 미완성 (계획대로 이번 범위 밖)

광산 채굴, 낚시, 씨앗·농사, 가구 제작, 새 2D 실내, NPC, 계절 이벤트, 온라인 멀티플레이, 효과음·배경음악.
광산·낚시터·농장은 위치와 상호작용 지점(`world.interacts`)이 준비돼 있어 지도를 다시 만들지 않고 연결할 수 있습니다.

## 남은 오류 / 위험 (알고 있는 것)

1. **실제 폰 시험을 하지 못함**: 저사양 폰에서의 속도, 터치 감각, 주소창 때문에 화면이 줄어드는 정도, 동시 터치(조이스틱 + 버튼)가 폰에서 매끄러운지 미확인.
2. **마을 첫 생성이 폰에서 느릴 수 있음**: 데스크톱에서 1.2~2초. 로딩 화면을 표시하고 한 번 만든 뒤에는 재사용하지만, 저사양 폰에서는 더 걸릴 수 있음.
3. **저장 공간**: 사진이 많이 쌓이면 폰 저장 공간 부족 가능(기존 한계, 안내 문구 있음).
4. 기기 시계를 바꾸면 낮밤·채집 갱신도 바뀜(서버 없이 동작하는 구조의 한계, 의도된 단순화).
5. 라이브 주소를 브라우저로 직접 열어 보는 시험은 하지 못함(파일 응답·일치만 확인).

## 시험 중 찾아 고친 문제

화면 시계가 음수가 되어 게임이 멈추는 문제, 반려동물이 방석에서 멈추는 문제, 쓰다듬기 후 반복 오류, 밭 위에 바위가 놓이는 문제, 나무 뒤에서 주인공이 가려지는 문제, 폰에서 전체 화면 요청이 거부될 수 있는 호출 순서, 업데이트 때 DB 업그레이드가 막힐 수 있는 문제. 자세한 내용은 `docs/TEST_RESULTS.md`.
