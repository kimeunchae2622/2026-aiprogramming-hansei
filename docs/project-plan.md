# 한 장 기획서

**프로젝트명(가칭)**: 반려동물 추억 저장소

- **형태**: 모바일 웹앱(PWA) — 홈 화면에 추가해 앱처럼 사용, 무료 정적 호스팅에 배포
- **접속 주소**: https://kimeunchae2622.github.io/2026-aiprogramming-hansei/
- **한 문장 설명**: 반려동물을 키우는 사람이 우리 아이의 추억과 일정을 나만 볼 수 있게 폰에 기록하고, 캐릭터를 돌보며, 근처 동물병원을 찾는 앱
- **데이터 저장**: 모든 기록은 사용자 폰 안에만 저장(서버·로그인 없음), 다른 사람과 공유하지 않음
- **개발 시간 한도**: 7시간

## 핵심 기능 (1개)
**추억 기록** — 글만 또는 사진과 함께 글을 올리는 개인 SNS형 피드
- 반려동물별 프로필(2마리 이상 등록, 선택해서 기록)
- 기록 보관: 백업 내보내기·불러오기

## 부가 기능 (3개)
1. **달력**: 병원 예약, 생일 등 일정 등록·조회 (푸시 알림 없음)
2. **캐릭터 돌보기**: 강아지/고양이, 직모/곱슬, 색 5종 선택. 밥·간식·놀이·씻기기·쓰다듬기 버튼, 움직임 없이 효과만
3. **동물병원 지도**: 공공데이터 기반 전국 동물병원 지도  
   (시간 여유가 있으면 반려동물 동반 시설 추가 — 막히면 동물병원만)

## 완료 기준 (3개)
1. 처음 쓰는 사람이 설명 없이 반려동물을 등록하고 글(글만/사진 포함)을 올릴 수 있다.
2. 휴대폰 화면에서 모든 기능이 불편 없이 동작하고, 무료 서버에 상시 접속 가능한 주소가 있다.
3. 사용자 입력 실수·빈 화면·데이터 없음 상황에서 오류 없이 안내 문구가 나오고, 백업한 파일로 기록이 복원된다.

## 안 할 것 (3개)
1. 다른 사람과 기록 공유, 로그인, 서버 저장
2. 사진으로 캐릭터 자동 생성(AI), 캐릭터 움직임 애니메이션
3. 지도에서 장소 직접 추가, 달력 푸시 알림

## 지킬 조건
실행 중 AI API 호출 금지 · 카드 등록 서비스 금지 · 실제 개인정보 금지(가짜 데이터·공공데이터만 사용)
