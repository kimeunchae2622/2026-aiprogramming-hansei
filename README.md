# 2026 인공지능 프로그래밍 (한세대)

일반인이 설명서 없이 사용할 수 있는 프로그램을 만드는 프로젝트입니다.

- 주제: **반려동물 추억 저장소** (나만 보는 모바일 웹앱)
- 형태: Windows 단독 실행형(.exe 1개) 또는 모바일 지원 웹(무료 서버)
- 접속 주소: https://kimeunchae2622.github.io/2026-aiprogramming-hansei/
- 상태: 핵심 기능·달력·동물병원 지도·우리 집 게임에 더해 **별빛 꼬리 마을**(가로 전체 화면 2D 픽셀 게임) 1차 구현 (기획서: docs/project-plan.md)

## 조건 요약
| 항목 | 내용 |
|---|---|
| 사용성 | 설명서 없이 일반인이 사용 가능 |
| AI API | 완성품 실행 중 호출 금지 (키는 수업시간에만 동작) |
| 서버 | 데이터 공유가 필요한 주제만 무료 서비스 허용, 카드 등록 서비스 제외 |
| 데이터 | 실제 개인정보 금지, 가짜 데이터 또는 공공데이터 사용 |
| 기능 | 핵심 1개 이상 + 부가 3개 |
| 개발 시간 | 7시간 이하 |
| 배포 | .exe 1개(설치 불필요) 또는 모바일 대응 웹 + 무료 상시 서버 |
| 웹일 경우 | 1주차 안에 빈 페이지라도 배포해 접속 주소 확보 |

## 별빛 꼬리 마을 (게임)
돌보기 탭 → **별빛 꼬리 마을 들어가기**. 폰을 가로로 돌려 우리 아이들과 마을을 산책하고, 꽃·열매·나뭇가지·반짝이는 조각을 채집하고, 상점에서 정원 가구를 사서 정원을 꾸밉니다.
- 설계: `docs/GAME_DESIGN.md` · 그래픽 출처: `docs/ASSET_SOURCES.md` · 시험 결과: `docs/TEST_RESULTS.md` · 개발 보고서: `docs/DEVELOPMENT_REPORT.md`

## 폴더 구조
- `docs/` 기획서, 설계, 과제 안내
- `js/`, `css/` 앱 소스 · `js/game/` 마을 게임 소스
- `src/` (비어 있음)
- `notes/` 수업 기록, 작업 로그 (`time-log.md`에 개발 시간 기록)
